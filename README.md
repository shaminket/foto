# Encardomy — Agenda Interactiva de Fotografía (2º Periodo ENP 4)

Aplicación web interactiva diseñada bajo el manual de identidad visual de **Encardomy (Concepto 3: Cursor Inteligente)** para compartir y agendar las sesiones y entregas de **Fotografía (Salón B301 fotografía)**.

## Identidad Visual Aplicada
- **Logotipo e Isotipo:** Cursor Inteligente (unión de cursor, documento con pliegue verde menta `#31C9BD` y letra `E` sobre azul eléctrico `#207FF9`).
- **Paleta Oficial:**
  - `#207FF9` Azul Eléctrico (Botones / CTA / Enlaces)
  - `#12396A` Azul Marino (Títulos / Encabezados / Modo oscuro)
  - `#FFFFFF` Blanco Puro (Fondo principal de tarjetas)
  - `#31C9BD` Verde Menta (Confirmaciones / Éxito / Garantías)
  - `#40464F` Gris Grafito (Texto y elementos secundarios)
  - `#EEF2F7` Gris Claro (Fondos suaves)
- **Tipografías:** `Sora` (Títulos, subtítulos y logo) + `Inter` (Párrafos, botones e información).

## Funciones para tus compañeros
1. **Preconfigurada para 2ª Sección y Jueves (12:50 – 14:30)** e ignorando por defecto los recuadros rojos de IPE.
2. **Filtros interactivos:** Cualquier compañero puede elegir qué sesiones marcar, cambiar a 1ª Sección, ajustar el día (Martes, Miércoles o Jueves) o su horario.
3. **Agendar en 1 clic:** Botón directo **"+ Agendar en Google Calendar"** en cada tarjeta, descarga de paquete `.ics` para Apple Calendar/Outlook/Google Calendar y botón para copiar los enlaces con formato para WhatsApp.
